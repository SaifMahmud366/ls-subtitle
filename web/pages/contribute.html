Contribution Guide

Learn how to contribute your AI-translated Bengali subtitles via GitHub Pull Request.

5-Step Contribution Flow

1
Fork the Repository

Navigate to github.com/SaifMahmud366/ls-subtitle and click the Fork button in the top right.

2
Clone & Create a Branch

Clone your fork locally and create a descriptive branch: git checkout -b add-jujutsu-s02

3
Place Subtitles in the Exact Folder

Place your .srt or .zip files into the proper path under Subtitles/ as shown below.

4
Commit and Push

Commit your changes with a clear message: git commit -m "feat(subtitles): add Jujutsu Kaisen S02 Bengali subs"

5
Submit a Pull Request

Open a Pull Request to merge your branch into main. Maintainers will review and merge it.

Required Directory Structure

folder-spec.txt 
Subtitles/
├── Anime/
│   └── {ReleaseYear}/{ShowName}/{Season}/*.srt     (or CompleteSeason.zip)
├── Movies/
│   └── {ReleaseYear}/{MovieTitle}/*.srt            (or MovieCollection.zip)
└── Tv-series/
    └── {ReleaseYear}/{SeriesName}/{Season}/*.srt   (or CompleteSeason.zip)

File Guidelines

  • Encoding: All .srt files must be saved with UTF-8 encoding so Bengali script displays without corrupt characters.
  • Naming Convention: Use dot-separated release naming (e.g. Jujutsu.Kaisen.S02E01.Bangla.srt).
  • Allowed Extensions: Only .srt and .zip are indexed. Please do not commit video files, text notes, or torrents.
