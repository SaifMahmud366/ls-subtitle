About ls-subtitle

A clean, high-performance static file index for AI-translated Bengali subtitles.

Project Overview

ls-subtitle is a minimalist, modern static web index designed to browse and download AI-translated Bengali subtitles directly from a GitHub repository.

Built for cinephiles, anime fans, and developers, it transforms the GitHub repository directory structure into a fast, tactile file explorer with zero server overhead.

How It Works (Zero Backend)

Automated Tree Discovery

On page load, it queries GitHub's REST Trees API (git/trees/main?recursive=1) to construct folder hierarchies on the fly.

Single-Click Downloads

Clicking any subtitle or season pack immediately streams the raw file from GitHub with instant toast feedback.

Always Fresh

Tree data is fetched fresh on every load (cacheTTL: 0) so newly pushed subtitles appear immediately. Use the refresh button to re-sync without reloading.

Pure Static Hosting

No database, Node server, or backend needed. Hosted directly via GitHub Pages as lightweight static files.

Supported File Types

.srt

Individual UTF-8 encoded Bengali subtitle file for movies or single episodes.

.zip

Complete season packs containing multiple .srt subtitles for binge-watching.
